**Interfacing entities.** The {{csci.abbrev}} CSCI (source) and the regional C2 system (destination).

**Transport.** Persistent TLS 1.3 connection with mutual certificate authentication, initiated by the {{csci.abbrev}} CSCI. Only the C2 system's certificate, issued by the program PKI, is accepted.

**Format.** Cursor-on-Target (CoT) XML events per the program-tailored schema, one event per track.

**Timing.** The complete track picture is transmitted at 1 Hz. If the connection is lost, tracks are not queued; transmission resumes with current state on reconnection.

| Data element | CoT attribute | Notes |
|---|---|---|
| Track identifier | event/@uid | Stable for the life of the track |
| Position | point/@lat, point/@lon | WGS-84 decimal degrees |
| Course and speed | track/@course, track/@speed | Degrees true; m/s |
| Vessel identity | detail/ais/@mmsi | Present for AIS-fused tracks only |
| Time of validity | event/@time | UTC, ISO 8601 |
<!-- variant: summary -->
Outbound 1 Hz Cursor-on-Target track feed to the regional C2 system over mutually authenticated TLS 1.3.
